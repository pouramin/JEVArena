JEVArena Portable for Windows
=============================

1. Extract this ZIP to a normal folder.
2. Double-click START_JEVARENA.bat.
3. Your browser opens automatically.
4. Close the console window when you are finished.

No Node.js, npm, Python, API key, or account is required.
The portable package runs a tiny local static server using Windows PowerShell.
